# Personal landing page

A dependency-free personal landing page built for static hosting on GitHub Pages.

## Preview locally

From this directory, start Python's built-in static server:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000>. Stop the server with `Ctrl+C`.

Opening `index.html` directly also works, but the local server more closely
matches GitHub Pages behavior.
